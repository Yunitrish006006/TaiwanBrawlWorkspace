# 佈局工作台

在 `TaiwanBrawlWorkspace` repo 內執行：

```sh
npm run layout-studio
```

瀏覽器開啟 <http://127.0.0.1:9080>。只監聽本機，不需登入、網路或外部套件；草圖自動存在此瀏覽器的 localStorage。

## 兩個階段

1. **草圖**：新增 UI 元件、拖曳位置、拉右下角調整尺寸；右側可以輸入座標／尺寸，指定「在下方、上方、左側、右側、包含、置中對齊」關係。虛線顯示關聯。可切換 320、390、768、1280 寬度預覽。
2. **視覺細化**：沿用同一份版面，套用台灣寫實像素、舊紙木色或深色工作台風格；可改整體色板或單一元件的底色、文字色、強調色、圓角與字級。

「儲存草圖」寫入目前瀏覽器，包含目前的設計階段；重開工作台會回到保存的草圖或視覺細化階段。「匯出規格」下載 JSON，記錄階段、視窗尺寸、元件位置／大小、相對關係與色彩樣式。「匯入版面」會驗證規格版本、畫布邊界、元件類型和關係後才套用，不合法檔案不會覆蓋目前草圖。重設只影響此工具的獨立 localStorage key。
