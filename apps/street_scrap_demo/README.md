# 街角拾荒：寫實像素美術／操作 Demo

從 coordination repository 執行：

```sh
node apps/street_scrap_demo/server.mjs
```

瀏覽器開啟 http://127.0.0.1:8093 。以 Ctrl-C 停止。僅監聽本機，無登入、無部署、無外部素材或字型請求；不需網際網路，但重新開頁需要本機伺服器運作。

`http://127.0.0.1:8093/preview.html` 可切換320／390／768／1280寬度並量測排版；它是CSS viewport檢查，不代表實體手機測試。詳情大字模式不放大棋盤內小標，完整物品資訊顯示於可放大的詳情區。

規則由 `/design.json` 讀取 canonical `data/` 與企劃配方；本資料夾是一次性設計驗證，不是正式第三遊戲引擎。SVG 使用整數像素形狀，以便調整寫實比例與材質；尚非完整遊戲美術包。

## 可操作

- 點選物件→點空格移動、R／按鈕旋轉、滑鼠拖放。
- 四張紙屑打包與手動拆包，保存個別品質。
- 木條×3＋釘件束×1，依序點釘點1→2→3；失手降低品質，取消已開始的操作結算失手；重載恢復未完成操作。
- 原生／加工木板都可交付同一示範委託。
- 強化輪廓、隱藏標籤、大字模式。
- 專用 localStorage key `street-scrap-art-demo-v1`；重設只影響本 Demo。資料未跨分頁同步，不可當正式存檔使用。

## 邊界

初始背包、兩塊木板委託、釘點操作及自動挑選投入材料是展示設定；正式版需實作手動材料選擇與完整訂單系統。沒有正式恢復體力計時、角色移動、倉庫、完整探索／料理／釣魚、跨裝置同步或資源下載。頁面仍在時可離線操作；不宣稱 service worker 離線安裝或關閉伺服器後可重新開頁。
